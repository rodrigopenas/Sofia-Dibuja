# Sofía Dibuja
App Android 13 liviana, sin internet. Lección de pez con 6 pasos, trazo progresivo, voz del sistema en español y botones para avanzar, volver y repetir. La voz depende del motor TTS instalado en la tablet.

## APK
Ir a Actions > Compilar APK Android 13 > última ejecución verde > Artifacts > Sofia-Dibuja-Android13-APK. Descomprimir el artefacto para obtener `app-debug.apk`. Esta es una APK de prueba firmada por Android para desarrollo.
